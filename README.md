# Xiao ZHOU's Personal Website

Source of [simonwicks1.github.io](https://simonwicks1.github.io/), built with Jekyll on the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template.

- Site settings and sidebar profile: `_config.yml`
- Navigation bar: `_data/navigation.yml`
- Pages (About, Experience, CV, Awards & Service): `_pages/`
- Publications: `_publications/`
- PDFs and videos: `files/`; images: `images/`

Preview locally with `bundle install && bundle exec jekyll serve`.
